# STREAMHUB

Десктопная видеостена и сервер трансляций для RTSP/HTTP источников. Текущая подготовленная версия — **1.6.4**.

## Установка

После публикации установщик `STREAMHUB-Setup-1.6.4.exe` будет доступен в разделе **Releases** репозитория. Не загружайте его в исходный код: файл превышает лимит GitHub для обычных файлов. На Windows запустите установщик и откройте STREAMHUB через ярлык.

При обновлении с ранних версий установщик останавливает и отключает автозапуск старой службы `VideowallServer`, сохраняя её регистрацию и данные. Сведения об изменениях и непроверенных сценариях — в [CHANGELOG.md](CHANGELOG.md).

## Разработка

- `src/` — Electron, сервер, интерфейс и зависимости Node.js.
- `installer/` — сценарий NSIS. Для воспроизводимой сборки нужны Windows Electron runtime, FFmpeg, MediaMTX и ресурсы в `stage160/`, а также исполняемый payload в `payload160/`; эти файлы не входят в репозиторий.
- `tests/` — тесты логики.

Запуск проверок из корня репозитория:

```bash
node --test tests/*.test.cjs
```

Перед публикацией новой сборки проверьте её на Windows с реальными камерами, в частности воспроизведение, запись TCP/UDP, студию и установку поверх предыдущей версии. Само наличие EXE в Releases не означает, что эти сценарии проверены.
